Llamadas a APIs de LLM

Introducción

Hasta ahora, hemos explorado Ollama para ejecutar modelos de forma privada en nuestra propia máquina. Sin embargo, en el mundo real, los desarrolladores rara vez despliegan modelos masivos en el servidor del usuario final. Para construir aplicaciones robustas, escalables y con capacidades de razonamiento avanzado (como las que ofrecen los modelos propietarios de última generación), necesitamos interactuar con LLMs a través de APIs.

Factores que se deben tener en cuenta al elegir una API de LLM:

  • Infraestructura:
    • Ventajas: Escalabilidad ilimitada. Se delega el cómputo pesado y el auto-escalado al proveedor.
    • Desafíos: Dependencia del proveedor (Vendor Lock-in). Existe una sujeción a la disponibilidad y políticas del servicio contratado.
  • Evolución del modelo:
    • Ventajas: Acceso instantáneo a modelos con mejoras continuas en razonamiento y ventanas de contexto.
    • Desafíos: Latencia de red. La comunicación externa introduce un factor temporal ausente en el procesamiento local.
  • Gestión y Operaciones:
    • Ventajas: Mantenimiento nulo. Se eliminan las tareas de parches, drivers y gestión de GPUs; el sistema se mantiene actualizado de forma automática.
    • Desafíos: Estructura de costes. El esquema de pago por uso puede escalar exponencialmente si no se optimiza el consumo de tokens.
  • Integración y Ecosistema:
    • Ventajas: Facilidad de integración. Las APIs facilitan la conexión con herramientas, bases de datos vectoriales y frameworks de agentes.
    • Desafíos: Limitaciones de uso. Se opera bajo Rate Limits (límites de tasa) y políticas de filtrado que pueden restringir el flujo de trabajo.
  • Privacidad y Seguridad:
    • Ventajas: Seguridad gestionada. Los proveedores suelen implementar medidas de seguridad robustas para proteger los datos.
    • Desafíos: Exposición de datos. Enviar datos sensibles a través de la red puede plantear riesgos de privacidad, especialmente si no se cifran adecuadamente.
  • Personalización:
    • Ventajas: Modelos preentrenados. Acceso a modelos de última generación sin necesidad de entrenamiento o ajuste fino.
    • Desafíos: Falta de control. No se puede personalizar el modelo ni ajustar su comportamiento más allá de los parámetros de la API.
  • Coste:
    • Ventajas: Sin costes iniciales. No se requiere inversión en hardware o infraestructura. Se paga por uso. Algunos proveedores ofrecen planes gratuitos o de bajo costo para comenzar.
    • Desafíos: Costes operativos. El uso continuo puede resultar costoso, especialmente con modelos de gran tamaño o alto volumen de solicitudes.
  • Estandarización:
    • Ventajas: Interfaz unificada. Las APIs proporcionan una interfaz consistente para interactuar con diferentes modelos y proveedores. El estándar de facto es el formato de solicitud de OpenAI, lo que facilita la integración con múltiples servicios.
    • Desafíos: Fragmentación del mercado. La falta de estándares comunes puede dificultar la migración entre proveedores o la integración de múltiples servicios.

Ollama a través de API de OpenAI

Ollama ofrece una API compatible con el formato de solicitud de OpenAI, lo que facilita la integración con aplicaciones que ya utilizan este estándar. Para interactuar con Ollama a través de su API. OpenAI tiene dos APIs principales:

  • API de Chat: Permite enviar mensajes en formato de conversación, ideal para aplicaciones de chatbots o asistentes virtuales.
  • API de Completions: Permite enviar un prompt y recibir una respuesta generada, ideal para tareas de generación de texto o completado de código.

Las APIs de OpenAI se puede ejecutar a través de HTTP utilizando herramientas como curl o bibliotecas de cliente en diversos lenguajes de programación como Python, JavaScript, etc.

Roles en la API de Chat

En la API de Chat, los mensajes se estructuran con roles específicos que definen el contexto de la conversación:

  • system: Define el comportamiento general del modelo. Por ejemplo, “Eres un asistente útil.”
  • user: Representa las entradas del usuario. Por ejemplo, “¿Cuál es la capital de Francia?”
  • assistant: Representa las respuestas generadas por el modelo.

Ejemplo de uso con curl

curl -X POST "http://localhost:11434/v1/chat/completions" \
     -H "Content-Type: application/json" \
     -d '{
           "model": "llama3.2:1b",
           "messages": [
             {"role": "system", "content": "Eres un guía turístico."},
             {"role": "user", "content": "¿Cuál es la capital de Francia?"}
           ]
         }'

Ejemplo de uso con request (Python)

Haz clic para ver el código 
import requests

    ]
}

Ejemplo de uso con openai (Python) - API de Chat

Haz clic para ver el código 
from openai import OpenAI
MODEL = "llama3.2:1b"
openai = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

response = openai.chat.completions.create(
 model=MODEL,
 messages=[{"role": "user", "content": "¿Cuánto son 2 + 2?"}]
)

print(response.choices[0].message.content)
2 + 2 es igual a 4.

Ejemplo de uso con openai (Python) - API de Completions

Haz clic para ver el código 
from openai import OpenAI

client = OpenAI(
    base_url='http://localhost:11434/v1/',
    api_key='ollama'
)

response = client.completions.create(
    model="llama3.2:1b",
    prompt="Escribe un refrán corto sobre la perseverancia:",
    max_tokens=50
)

print(response.choices[0].text)
"La ley del camino: no te rindas, el destino lo logrará."

Gemini

Gemini es un modelo de lenguaje desarrollado por Google que se destaca por su capacidad de razonamiento avanzado y su amplia ventana de contexto. Gemini se puede acceder a través de la API se necesita una cuenta de Google Cloud y configurar el acceso a la API de Gemini. Últimamente, Google ha modificado los límites de uso de sus API y ahora Gemini es prácticamente inservible. Sin embargo, aquí hay un ejemplo de cómo se podría usar la API de Gemini:

Haz clic para ver el código 
import os
from google import genai
from google.genai import types
from dotenv import load_dotenv

load_dotenv(override=True)
api_key = os.getenv('GOOGLE_API_KEY')

client = genai.Client(api_key=api_key)

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=[
        types.Content(
            role="user",
            parts=[
                types.Part.from_text(text="2+2")
            ]
        )
    ]
)

print(response.text)
2 + 2 = 4

Usando la el API de Chat de OpenAI:

Haz clic para ver el código 
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv(override=True)
api_key = os.getenv('GOOGLE_API_KEY')

MODEL = "gemini-2.5-flash"
openai = OpenAI(base_url="https://generativelanguage.googleapis.com/v1beta", api_key=api_key)

response = openai.chat.completions.create(
 model=MODEL,
 messages=[{"role": "user", "content": "¿Cuánto son 2 + 2?"}]
)

print(response.choices[0].message.content)
¡2 + 2 son 4!

GitHub Marketplace

GitHub Marketplace ofrece una variedad de aplicaciones y servicios que se integran con GitHub para mejorar el flujo de trabajo de desarrollo. Entre estas aplicaciones, hay varias que proporcionan acceso a modelos de lenguaje de distintos proveedores a través de APIs, lo que permite a los desarrolladores incorporar capacidades de inteligencia artificial en sus proyectos directamente desde GitHub.

Tiene su propia API:

Haz clic para ver el código 
import os
from azure.ai.inference import ChatCompletionsClient
from azure.ai.inference.models import SystemMessage, UserMessage
from azure.core.credentials import AzureKeyCredential
from dotenv import load_dotenv

load_dotenv(override=True)

endpoint = "https://models.github.ai/inference"
model = "deepseek/DeepSeek-V3-0324"
token = os.getenv('GITHUB_TOKEN')

client = ChatCompletionsClient(
    endpoint=endpoint,
    credential=AzureKeyCredential(token),
)

response = client.complete(
    messages=[
        SystemMessage("You are a helpful assistant."),
        UserMessage("2+2"),
    ],
    model=model
)

print(response.choices[0].message.content)
The sum of 2 + 2 is **4**. 

Let me know if you'd like help with anything else!

Hugging Face

Hugging Face es una plataforma que ofrece una amplia variedad de modelos de lenguaje y aprendizaje automático a través de su API de Inference Endpoints. Esta API permite a los desarrolladores acceder a modelos preentrenados para tareas como generación de texto, clasificación, análisis de sentimientos y más, sin necesidad de gestionar la infraestructura subyacente.

Haz clic para ver el código 
import os
from huggingface_hub import InferenceClient
from dotenv import load_dotenv

load_dotenv()
hf_token = os.getenv('HUGGINGFACE_API_KEY')

MODEL = "meta-llama/Llama-3.1-8B-Instruct"

client = InferenceClient(api_key=hf_token)

response = client.chat_completion(
    model=MODEL,
    messages=[{"role": "user", "content": "¿Cuánto son 2 + 2?"}],
    max_tokens=500
)

print(response.choices[0].message.content)
La respuesta es 4.

Usando la API de OpenAI:

Haz clic para ver el código 
import os
from openai import OpenAI
from dotenv import load_dotenv
load_dotenv(override=True)

api_key = os.getenv('HUGGINGFACE_API_KEY')
MODEL = "meta-llama/Llama-3.1-8B-Instruct"

openai = OpenAI(
    base_url="https://router.huggingface.co/v1",
    api_key=api_key
)

response = openai.chat.completions.create(
    model=MODEL,
    messages=[{"role": "user", "content": "¿Cuánto son 2 + 2?"}],
    max_tokens=500
)

print(response.choices[0].message.content)
La respuesta a la ecuación 2 + 2 es 4.

Puter.js

Puter.js permite ejecutar modelos de lenguaje directamente en el navegador sin necesidad de API KEYS. Cada usuario ejecuta el modelo en un espacio privado en la nube de Puter, lo que garantiza la privacidad y seguridad de los datos. Puter.js es compatible con una amplia gama de modelos, incluyendo GPT-4.5 nano, y ofrece una experiencia de usuario fluida y rápida. Para usar Puter.js, simplemente incluye su script en tu página HTML y llama a la función puter.ai.chat con el mensaje que desea enviar al modelo:

#| file: 20_demo1/index.html
    <html>
<body>
    <script src="https://js.puter.com/v2/"></script>
    <script>
        // Chat with GPT-5.4 nano
        puter.ai.chat(`2+2`, { model: "gpt-5.4-nano" }).then(puter.print);
    </script>
</body>
</html>

LiteLLM

LiteLLM es una biblioteca de Python diseñada para simplificar la integración de múltiples modelos de lenguaje (LLMs) en aplicaciones. Su objetivo principal es permitirte llamar a cualquier LLM (como los de OpenAI, Anthropic, Cohere, Google Vertex AI, Hugging Face, etc.) utilizando el mismo formato de entrada y salida.

En lugar de aprender y escribir código específico para cada SDK o API, LiteLLM estandariza el proceso bajo una interfaz común.

Prueba de LiteLLM con Ollama:

Haz clic para ver el código 
from litellm import completion

# Asegúrate de que Ollama esté ejecutándose en tu máquina
response = completion(
    model="ollama/llama3.2:1b",
    messages=[{"role": "user", "content": "¿Cuánto son 2 + 2?"}]
)

# Imprime el contenido de la respuesta
print(response.choices[0].message.content)
¡Un buen ejemplo de matemáticas básicas!

2 + 2 = 4. La respuesta es 4.

LiteLLM también puede ejecutarse como servidor proxy. Para instalar LiteLLM como proxy, ejecute desde la carpeta del proyecto:

uv add litellm[proxy]
uv tool install litellm

Para configurar por primera vez, ejecute:

uv run litellm --setup

Esto creará un archivo de configuración litellm_config.yaml en la raíz del proyecto, donde puede agregar sus claves API para los diferentes proveedores de LLM.

Para sucesivas ejecuciones, simplemente ejecute:

uv run litellm --config litellm_config.yaml --port 4000

Plantillas de promting

Introducción

Es habitual que, al trabajar con LLMs, se necesiten enviar prompts con formatos específicos. Para evitar tener que escribir el mismo código repetidamente y facilitar el mantenimiento, es recomendable crear plantillas de prompting (prompt templates) que permitan generar prompts de forma dinámica a partir de una estructura predefinida. Estas plantillas pueden incluir variables o marcadores de posición que se reemplazan con valores específicos en cada llamada a la API.

Jinja2

Una de las bibliotecas más populares para crear plantillas en Python es Jinja2. Esta biblioteca permite definir plantillas con una sintaxis sencilla y potente, que incluye variables, estructuras de control (condicionales, bucles) y filtros para manipular los datos.

Haz clic para ver el código 
from pathlib import Path
from IPython.display import display, Markdown
from jinja2 import Template

def load_file_contents(filename: str):
  with open(filename, "r", encoding="utf-8") as f:
    return f.read()

article = load_file_contents(
  Path(".").resolve() / '40_demo1/articles/how_to_reset_your_acme_password.md')

# Traducción de la plantilla del prompt
prompt_template: Template = Template("""
Eres un servicial Soporte de IA. Utiliza el siguiente artículo de soporte para responder preguntas. Solo utiliza el <article> proporcionado 
y, si no encuentras una respuesta, responde con: Lo siento, no puedo ayudarte con eso. Por favor, llama al servicio de atención al cliente al 555-555-1234.

<article>
{{article}}
</article>

Pregunta: {{question}}""")

# Traducción de la pregunta
question = "Tengo problemas con mi contraseña. ¿Puedes ayudarme a iniciar sesión?"

prompt = prompt_template.render(article=article, question=question)

display(Markdown(f"```markdown\n{prompt}\n```"))

# Cómo restablecer tu contraseña de Acme

Si has olvidado tu contraseña o necesitas actualizarla por motivos de seguridad, sigue los pasos a continuación para restablecerla y recuperar el acceso.

---

## 1. Restablecer tu contraseña desde la página de inicio de sesión de Acme

1. **Ve a la página de inicio de sesión de Acme**
   - Dirígete a: `https://acmecorp.com/`

2. **Selecciona "¿Olvidaste tu contraseña?"**
   - En la pantalla de inicio de sesión, busca el enlace "¿Olvidaste tu contraseña?" (a veces etiquetado como "¿No puedes acceder a tu cuenta?").
   - Haz clic o pulsa el enlace para iniciar el proceso de restablecimiento.

3. **Ingresa tu nombre de usuario o correo electrónico**
   - Proporciona el nombre de usuario o la dirección de correo electrónico asociada a tu cuenta de Acme.
   - En muchas organizaciones, este es tu correo electrónico corporativo.

4. **Revisa tu correo electrónico para obtener un enlace de restablecimiento**
   - Acme te enviará un enlace de restablecimiento de contraseña por correo electrónico.
   - Si no lo ves, revisa tu carpeta de **Spam** o **Correo no deseado**.

5. **Sigue el enlace de restablecimiento**
   - Haz clic en el enlace del correo electrónico para abrir la página de restablecimiento de contraseña.
   - Si se te solicita, responde a cualquier pregunta de seguridad que tu organización haya configurado.

6. **Crea una nueva contraseña**
   - Ingresa una nueva contraseña que cumpla con los requisitos de complejidad de tu empresa (por ejemplo: longitud mínima, combinación de letras, números y símbolos).

7. **Inicia sesión con tus nuevas credenciales**
   - Regresa a la página de inicio de sesión de Acme.
   - Usa tu nombre de usuario (o correo electrónico) y tu nueva contraseña para iniciar sesión.

---

## 3. Solución de problemas y consejos

- **No recibí el correo de restablecimiento**: Revisa tu carpeta de spam y verifica tu dirección de correo electrónico. Si el correo no está allí, contacta a tu mesa de ayuda de TI o Recursos Humanos.
- **Preguntas de seguridad**: Si configuraste preguntas de seguridad, recuerda las respuestas exactas. Si te bloquean el acceso, contacta a soporte.
- **Cuenta bloqueada**: Si estás bloqueado o si las opciones de autoservicio no funcionan, contacta a tu mesa de ayuda.
